01 What it does

Prompt to sound

Create sound objects from natural-language prompts using open-source neural audio models.

Arrange

Place and layer generated sounds in a DAW-like environment, right in the browser.

Export

Individual audio files or a complete mix. Also REAPER projects and Python scripts for the underlying command-line audio engine.

02 Installation

Tested on Linux; macOS and Windows should be almost identical. Clone or download the repository, then open a terminal in the sonofabrik directory.

1 Node.js dependencies

npm install

2 Python dependencies

A virtual environment is recommended.

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

3 Stable Audio Open

Download Stable Audio Open 1.0 from Hugging Face. It is a gated model, so you need a free account and token, plus the HuggingFace CLI. 

hf auth login
hf download hf://stabilityai/stable-audio-open-1.0/ --local-dir ./stable-audio-open-1.0

You should end up with a stable-audio-open-1.0 directory in the repository root.

03 Running

A Python backend and a web interface. Start the backend first.

1 Backend

python server.py

2 Interface

In a second terminal:

npm run dev

Then open http://localhost:5173/.
